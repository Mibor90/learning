# Observaciones sobre `CHATGPT.py`

- **Importación rígida de dependencias externas**: el script importa `pandas` y `pdfplumber` en el nivel superior. Si alguna de estas librerías no está instalada, el programa fallará antes de ejecutar `main()` y no mostrará un mensaje claro al usuario. Podrías envolver las importaciones en bloques `try/except` para dar instrucciones de instalación en lugar de un `ModuleNotFoundError`. 【F:CHATGPT†L4-L56】
- **Selección de PDF sensible al uso de mayúsculas**: `select_pdf()` solo busca archivos que terminen exactamente en `.pdf`. En sistemas que generan extensiones en mayúsculas (`.PDF`), el script dirá que no hay archivos disponibles aunque existan. Considera hacer la búsqueda insensible a mayúsculas. 【F:CHATGPT†L21-L35】
- **Asignación de cabeceras sin validar longitud**: en `dataframe_from_rows()` se asigna `df.columns = header` sin comprobar que ambas longitudes coincidan. Cuando el encabezado detectado tiene menos celdas (por combinaciones o celdas fusionadas), `pandas` lanzará un `ValueError`, interrumpiendo todo el flujo. Validar o rellenar el encabezado antes de la asignación evitaría este fallo. 【F:CHATGPT†L9-L18】
- **Dependencia de PIL/Wand para OCR no controlada**: `extract_with_ocr()` invoca `page.to_image()` fuera del bloque `try/except`. Si la instalación carece de los backends necesarios (por ejemplo, `Pillow` o `wand`), se lanzará una excepción antes de mostrar el mensaje de error amigable del `try`. Podrías capturar ese fallo para informar claramente al usuario. 【F:CHATGPT†L196-L232】
- **Interacción obligatoria por consola**: el script exige `input()` interactivo para elegir el PDF, pero no maneja `EOFError`. En automatizaciones (p. ej. ejecución vía cron) esa llamada terminará con un error. Manejar `EOFError` o permitir pasar la ruta por argumentos haría el flujo más robusto. 【F:CHATGPT†L29-L39】
